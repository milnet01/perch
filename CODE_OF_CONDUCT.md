# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, verbatim.

The canonical text is maintained upstream at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

For convenience, the same text in Markdown form:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md

By participating in this project (contributions, issues, discussions, reviews) you agree to abide by that document.

## Enforcement contact

Reports of unacceptable conduct may be sent to the project maintainer at the address listed on the repository's GitHub profile. Reports are handled confidentially.
